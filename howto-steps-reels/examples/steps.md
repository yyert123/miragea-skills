# How to Add a Voiceover to Any Video in 3 Steps
## Step 1: Save your voice once
Upload a clean thirty second clip to Miragea and keep the actor id it returns.

## Step 2: Write the script
Keep each sentence short, one idea per line, and read it aloud before you render.

## Step 3: Render and check
Run the skill, watch one frame per card, then post the Short with the SRT as captions.
